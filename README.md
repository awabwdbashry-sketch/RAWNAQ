# 🌟 RAWNAQ

## 🇸🇩 نبذة عن المشروع

**RAWNAQ** هو مشروع ويب حديث يهدف إلى تقديم تجربة رقمية أنيقة وسريعة، مع واجهة مستخدم متجاوبة تعمل بشكل ممتاز على أجهزة الكمبيوتر والهواتف والأجهزة اللوحية.

تم بناء المشروع باستخدام تقنيات الويب الأساسية مع التركيز على التصميم العصري، سهولة الاستخدام، وسرعة الأداء.

---

## ✨ المميزات

- 🎨 تصميم عصري وأنيق
- 📱 متجاوب مع جميع أحجام الشاشات
- 💻 يعمل على أجهزة الكمبيوتر واللابتوب
- 📲 متوافق مع الهواتف والأجهزة اللوحية
- ⚡ أداء سريع وخفيف
- 🧩 واجهة مستخدم منظمة
- 🌐 تجربة استخدام بسيطة وسلسة
- ✨ تأثيرات وحركات تفاعلية
- 📐 تصميم Responsive

---

## 🛠️ التقنيات المستخدمة

- ⚡ JavaScript
- 📱 Responsive Web Design
